# Mini_ECOM

A modern, full-stack **e-commerce and inventory management platform** designed to showcase robust software engineering skills and best practices. Built with a scalable **Express (Node.js) backend** and a dynamic **React frontend**, Mini_ECOM demonstrates end-to-end workflow for product management, customer ordering, real-time inventory, and operational efficiency features commonly required in retail and logistics domains.

---

## Key Highlights

- **Full-Stack Implementation:** Leveraging React for a responsive client experience and Express/Node.js for performant API design.
- **Role-Based Access:** Separate interfaces and permissions for Merchants (admins) and Customers to emulate real-world user hierarchy.
- **Optimized Order Fulfillment:** Intelligent backend logic generates the most efficient delivery sequence for outstanding orders, simulating vehicle routing—a valuable feature for scaling online retail.
- **Customer-Centric UX:** Seamless customer journeys, including registration, address management, real-time inventory check, and an intuitive shopping cart/checkout flow.
- **Operational Dashboards:** Merchants can manage both products and customers, view complete order tracking, and monitor key business operations from a central panel.

---

## Feature Overview

| Feature                      | Details |
|-----------------------------|---------|
| **User Roles**               | Merchants: Add & manage products, control inventory, manage customers & orders, view optimized delivery routes. <br> Customers: Register, update addresses, browse inventory, place orders, view history. |
| **Product & Inventory**      | Real-time inventory updates. Checkout limited to in-stock products. Merchants can edit, add, or remove products. |
| **Order & Address Management** | Orders require a customer address. Customers can store and manage multiple addresses. |
| **Delivery Route Optimization** | For all active/pending orders, the system suggests the most efficient stop sequence, supporting effective logistics. |
| **Customer Management**      | Merchants have tools to view, audit, and engage with customers and their orders. |
